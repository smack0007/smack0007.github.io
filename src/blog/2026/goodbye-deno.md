Date: 2026-10-12

For almost as long as [deno](https://deno.com) has been around I've been using
it for one thing or another. Last Friday on October 9th, 2026 deno announced
that it is [joining Cloudflare](https://deno.com/blog/cloudflare) and that the
runtime will only receive updates for the next year and the development will
stop. This saddens me but all good things must come to an end and so this
morning with help of local AI I converted the blog back to running on node.
